1. PHP.ini REQUIREMENTS
================================================================================

The following PHP.ini values must be set (or exceeded) for the platform to
function correctly, especially for file uploads and form processing.

+-------------------------+----------------+----------------------------------+
| DIRECTIVE               | MINIMUM VALUE  | REASON                           |
+-------------------------+----------------+----------------------------------+
| upload_max_filesize     | 10M            | Medical reports + device photos  |
| post_max_size           | 12M            | Must exceed upload_max_filesize  |
| max_execution_time      | 120            | File uploads + DB operations     |
| max_input_time          | 120            | Large form submissions           |
| memory_limit            | 128M           | Image processing + PDO queries   |
+-------------------------+----------------+----------------------------------+

Location of php.ini:
  - XAMPP: C:\xamppl\php\php.ini
  - WAMP:  C:\wamp64\bin\php\php[version]\php.ini

After editing php.ini, restart Apache via XAMPP/WAMP control panel.

Verify settings: Create a phpinfo.php file in the web root with
<?php phpinfo(); ?> and check the "Loaded Configuration File" path.

3. DATABASE CONFIGURATION
================================================================================

Step 3.1 â€” Edit includes/config.php

  The file is located at: sanad/includes/config.php

  Default XAMPP/WAMP credentials (change if your setup is different):
    define('DB_HOST', 'localhost');
    define('DB_USER', 'root');
    define('DB_PASS', '');          // Empty for XAMPP
    define('DB_NAME', 'sanad_db');

  For WAMP with password:
    define('DB_PASS', 'your_password_here');

Step 3.2 â€” Auto-Setup Mechanism

  NO manual database import is required. On every page request,
  includes/db.php automatically:

    1. Connects to MySQL with no database selected
    2. Runs: CREATE DATABASE IF NOT EXISTS sanad_db
    3. Runs: USE sanad_db
    4. Creates all 4 tables via CREATE TABLE IF NOT EXISTS:
       - users
       - devices
       - device_photos
       - requests

  If the database already exists with all tables, these queries are no-ops
  and have zero performance impact.

Step 3.3 â€” Verify Connection

  Simply load any page (e.g. http://localhost/sanad/). If you see the
  homepage, the database is connected. If you see an error, check:
  - MySQL service is running
  - DB_HOST, DB_USER, DB_PASS in config.php match your MySQL credentials
  - No MySQL port conflicts (default: 3306)

4. MAPS — Leaflet.js + OpenStreetMap (FREE, NO API KEY)

The platform uses Leaflet.js (open-source) with OpenStreetMap tiles for:
  - Interactive map picker on add-device.php (search + click to place marker)
  - Embedded map display on device.php (device detail page)
  - Location search via Nominatim (free OpenStreetMap geocoding API)

NO API key is required. Maps work out of the box with zero configuration.

Step 4.1 — How It Works
  Map rendering: Leaflet.js loaded from unpkg CDN (free)
  Map tiles: OpenStreetMap tiles (free, no API key, no usage limits)
  Geocoding: Nominatim API via includes/geocode.php (free, no API key)

Step 4.2 — CDN URLs (in includes/config.php)
  define('LEAFLET_CSS', 'https://unpkg.com/leaflet@1.9.4/dist/leaflet.css');
  define('LEAFLET_JS', 'https://unpkg.com/leaflet@1.9.4/dist/leaflet.js');

Step 4.3 — Fallback Behavior
  If Leaflet CDN fails to load (e.g. no internet), the platform falls back to:
  - Device detail page: Static fallback image + coordinates as text
  - Add device form: Manual coordinate input fields (latitude/longitude)

Step 4.4 — View on Google Maps Link
  After the fallback, a link to "https://www.google.com/maps?q=lat,lng"
  opens Google Maps in a new tab — this is a free link, NOT an API call.

6. TROUBLESHOOTING
================================================================================

PROBLEM: White screen / blank page on all pages
  CAUSE:  PHP fatal error, error display disabled
  FIX:
    1. Open php.ini
    2. Set: display_errors = On
    3. Set: error_reporting = E_ALL
    4. Restart Apache
    5. Reload page â€” error message will appear
    6. Common causes: missing extensions (pdo_mysql), syntax errors

PROBLEM: "Database connection failed" error
  CAUSE:  MySQL not running or wrong credentials
  FIX:
    1. Verify MySQL is running: XAMPP/WAMP control panel shows green
    2. Click "MySQL" â†’ check port (default: 3306)
    3. In config.php, verify DB_HOST, DB_USER, DB_PASS
    4. Try connecting via command line:
         mysql -u root -p
       (press Enter for blank password in XAMPP)
    5. If MySQL runs on non-standard port, add port to DSN in db.php:
         "mysql:host=localhost;port=3307"

PROBLEM: File upload fails (no error message)
  CAUSE:  File exceeds upload_max_filesize or post_max_size
  FIX:
    1. Check php.ini values (see Section 1)
    2. upload_max_filesize must be â‰¥ 10M
    3. post_max_size must be â‰¥ upload_max_filesize + 2M (min 12M)
    4. Restart Apache after changes
    5. Try uploading a smaller file (< 1MB) to isolate issue

PROBLEM: File upload fails with "Invalid file type" error
  CAUSE:  File extension not in whitelist
  FIX:
    1. Allowed extensions: jpg, jpeg, png, webp, pdf
    2. Check that MIME type matches extension (finfo_file() validates)
    3. Renaming .jpg to .jpeg will not bypass MIME check

PROBLEM: "419 Session expired" or CSRF token error
  CAUSE:  Session expired or token mismatch
  FIX:
    1. Default token lifetime: 7200 seconds (2 hours) â€” see config.php
    2. Increase: define('CSRF_TOKEN_LIFETIME', 14400);
    3. Clear browser cookies and session data, re-login

PROBLEM: Map not showing (blank gray area)
  CAUSE:  Leaflet CDN not loading (no internet or CDN blocked)
  FIX:
    1. Check that unpkg.com is accessible from your network
    2. If behind a firewall/proxy, download Leaflet locally:
       - Download leaflet.js + leaflet.css from https://unpkg.com/leaflet@1.9.4/
       - Place in assets/js/ and assets/css/ respectively
       - Update URLs in maps.js and config.php to local paths
    3. Fallback: Static map image + manual coords will display without Leaflet

PROBLEM: 404 Not Found on admin pages
  CAUSE:  Missing /admin/ subdirectory or incorrect URL
  FIX:
    1. Verify the folder sanad/admin/ exists with: index.php, listings.php,
       requests.php, users.php, action.php
    2. Access via: http://localhost/sanad/admin/index.php
    3. Ensure you are logged in with admin role

PROBLEM: Registration fails, "Email already exists"
  CAUSE:  Duplicate email in database (UNIQUE constraint)
  FIX:
    1. Use a different email address
    2. Or delete existing user manually via phpMyAdmin:
       DELETE FROM users WHERE email = 'existing@email.com';
